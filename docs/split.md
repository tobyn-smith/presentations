## Two interactions only

1. **Five growers (1:30-3:30):** sort what the selected cases show from what they do not establish. The key correction is that a shared feature in five fast-growing cases does not show that the feature caused growth.

Do not run the old five-minute pairs activity. It would push the discussion beyond the 15-minute limit.
